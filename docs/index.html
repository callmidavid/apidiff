How Apidiff Works

  1. API = The contract — what fields your app promises, like { email, name }
  2. Diff = Compare old vs new — like git diff but for APIs
  3. Breaking = Removed / renamed field = old apps will crash ❌
  4. Safe = Added field = old apps can ignore it ✅

For David

What does BREAKING mean?

If you deploy v2 as-is, any client reading user.email will fail. Restore email or ship as /v2/users with a migration note.

What does SAFE mean?

Adding phone is safe. Old clients ignore new fields. No crash.
